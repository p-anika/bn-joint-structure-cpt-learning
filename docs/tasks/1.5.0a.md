## Goal

The repo has several Markdown files written at different times. Some are plans made before the
work was done, and some contain known mistakes. This step checks every section of each one
against what actually exists: the code, the result files, the git history and
`docs/research-plan.md`. Each section gets a verdict:

- **accurate**: still true;
- **outdated**: was true or reasonable once, but things have changed;
- **wrong**: contradicts the code, the results or what Jirka said.

Each section also gets an action. The goal is CLAUDE.md's rule of **one source of truth per
topic**. Anything still correct moves into the current docs. Everything else is deleted. Git
history keeps old versions, and the decision log records where.
