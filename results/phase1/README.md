# results/phase1/: Phase 1 two-stage baseline

This folder is the **record of what was reported to Jirka on Sep 7, 2026**. It is never
overwritten: corrected or new results go to [`results/phase1.5/`](../phase1.5/README.md).

Command: `make phase1` (stages and design: `docs/code-guide/phase1-pipeline.md`). Since step
1.5.1, `make phase1` no longer makes `cpt-type-summary.csv` (decision log entry 57).
Write-up of the results: [`docs/reports/phase-1.md`](../../docs/reports/phase-1.md).
Moved here from `results/` in step 1.5.0b; contents unchanged.
