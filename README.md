# BN Joint Structure + CPT-Type Learning

Learning a Bayesian network's structure and each node's CPT type (STD, MLR or OLR) together,
with safe pruning rules. Research project with Dr. Jiří Vomlel (UTIA, Prague).

A full README (how to run each phase) arrives in steps 1.5.0b and 1.5.6. Until then:

- `docs/research-plan.md`: the plan (the only one).
- `docs/setup.md`: how to build the environment (WSL2, Python, R, scoring2a, SCIP, GOBNILP).
- `docs/reports/`: one report per step; `phase-1.md` is the Phase 1 baseline report.
- `docs/decision-log.md`, `docs/experiment-log.md`: every decision and every run.
- `docs/README.md`: the map of the `docs/` folder.
